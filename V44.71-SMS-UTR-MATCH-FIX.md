# V44.71 — Instant SMS UTR Match / Mismatch Fix

- Merchant Verify Android app sends actual SMS UTR/reference, exact amount, and SMS timestamp.
- Website server compares the real SMS UTR against the customer's submitted UTR.
- If the UTR does not match and the payment amount/time identifies one clear pending order, that order is immediately rejected.
- Correct UTR + exact amount continues to the normal automatic approval/ID release flow.
- Ambiguous same-amount orders are never guessed.
