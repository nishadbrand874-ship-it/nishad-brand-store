# V44.72 — UTR mismatch when SMS arrives before website UTR submit

Fixes the ordering race where the Merchant Verify app had already stored the real payment SMS before the customer submitted a wrong UTR. The UTR submit endpoint now checks recent Merchant Verify SMS records for the exact order amount and rejects the order when there is exactly one unambiguous recent SMS whose UTR differs from the submitted UTR. Multiple same-amount SMS records remain ambiguous and are not guessed.
